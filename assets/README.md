# Logo

`logo.svg` is `r = x`: the name read as an equation, `=` being how .rx writes
one (an equation stays true). The two bars are two colours, two values held
equal.

- Tile `#12233D`, corner radius 22 of 100. On a dark ground the tile can be
  `#1F3B63`.
- Letters `#FFFFFF`, JetBrains Mono ExtraBold at 38/100, outlined to paths, so
  the SVG needs no font.
- Top bar `#5B9BE6`, bottom bar `#F0B44C`, 7/100 thick with round caps.

`tooling/vscode-rx/icon.png` is this SVG rendered at 256 px.
